## よくある質問

**安いVPSは遅いですか？**

同じ「安い」でもCPUの世代とストレージで差が出ます。Vultrの$2.50〜$5は旧世代Intelに通常SSD、$6以上のHigh PerformanceはAMD EPYCかIntel XeonにNVMe。国内でもDDPSはNVMe標準、ConoHaはSSDで、同じ2GB台でも中身が違います。月100円差でストレージの種類が変わるなら、体感差のほうが大きい。

**転送量に上限があると何が困りますか？**

DDPSの2GBは月1TB、Vultrの$5は1TBです。テキストと画像中心のサイトなら1TBに届くことはほぼありませんが、動画や大きめのファイルを配布すると話が変わります。ConoHaは転送量0円・無制限を明記しているので、この項目だけなら国内勢に分があります。

**契約の途中でプランを変更できますか？**

XServer VPSは契約途中でもアカウントの「プラン変更」から変更できると公式FAQに書かれています。ConoHaはスケールアップ・ダウンに対応。Vultrは時間課金なので、上位プランに作り直して下位を削除する運用が基本になります。

**サーバーを止めれば料金も止まりますか？**

Vultrは止まりません。課金はデプロイ時から始まり、停止中も継続します。削除して初めて止まります。短期検証のつもりなら、必ず削除までセットで。

**$300クレジットがあれば無料で使えますか？**

クレジットは対象製品の利用料に充当されるもので、新規顧客限定、他のオファーと併用不可。$5プランの価格が変わるわけではなく、使い切れなかった分は現金として戻りません。返金ポリシー上、クレジットは返金不可です。
